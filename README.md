# Снежная дуэль

Unity-проект курсовой работы: пошаговая дуэль двух Android-телефонов через Bluetooth Classic.

Открывайте папку **project** в Unity **6000.3.10f1**.

- [Сборка, управление и запуск на двух телефонах](project/README.md)
- [Обновление 0.3: своё представление, прицел и камера — снимки и проверки](project/Documentation/OWNER_VIEW.md)

APK, кэш Unity и локальные отчёты сборки не хранятся в Git. Собрать APK: **Frost Duel → Build Android APK**.
